API Documentation

Every endpoint under /api/v1 requires the X-API-Key header.

Using this from Postman
  1. In Postman: File → Import → Link, paste {{ request.url_root }}api/v1/openapi.json — this creates a ready-made collection with every endpoint and parameter below.
  2. On the collection (or an individual request), add a header X-API-Key with the value below.
X-API-Key: {{ api_key or "NOT SET - add API_KEY to .env" }}
Cheat sheet — common queries

Every example below needs the X-API-Key header shown above. Full parameter reference (with descriptions) is in the interactive docs below — this is just the fast path for the questions people actually ask.

One employee, a date range
curl -H "X-API-Key: <key>" \
  "{{ request.url_root }}api/v1/attendance?employee_id=23&from_date=2026-08-01&to_date=2026-08-31"
One record, by its API id
curl -H "X-API-Key: <key>" \
  "{{ request.url_root }}api/v1/attendance/4821"
Filter by punch type
curl -H "X-API-Key: <key>" \
  "{{ request.url_root }}api/v1/attendance?punch_type=Check+In"

Valid values come from GET /attendance/filters below. status is a separate field (device verification method, e.g. fingerprint vs. password) — it is not check-in/out state. Filter on that with ?status=1 if you specifically need it.

Is there any new data? (polling / integration)
curl -H "X-API-Key: <key>" "{{ request.url_root }}api/v1/stats"
# -> remember "latest_id" from the response, e.g. 46132

curl -H "X-API-Key: <key>" \
  "{{ request.url_root }}api/v1/attendance?since_id=46132&sort_by=id&sort_dir=asc"
# -> only records inserted after id 46132.
# empty "data" = nothing new yet. Otherwise take the highest
# "id" you received and use it as the next since_id.

since_id is keyed off the auto-incrementing row id, not a timestamp — safe even if a device's clock drifts or a punch gets backdated.

Export to CSV
curl -H "X-API-Key: <key>" \
  "{{ request.url_root }}api/v1/attendance/export.csv?branch=CTG+Office" \
  -o attendance.csv

Accepts the same filters as the list endpoint, including since_id.

What values can I filter on right now?
curl -H "X-API-Key: <key>" \
  "{{ request.url_root }}api/v1/attendance/filters"

Returns the current branches, device IPs/serials, punch types and status codes actually present in the data.
